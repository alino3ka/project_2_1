# Анализ факторов, влияющих на рейтинг фильмов: от жанра до названия

## Описание проекта

Цель проекта — исследовать, какие факторы влияют на рейтинг фильмов.  
В качестве источника использована подборка топ-фильмов с сайта [FilmPro.ru](https://filmpro.ru/movies/top).

Мы провели:
- автоматизированный сбор данных (парсинг HTML с Selenium),
- очистку и нормализацию признаков (жанры, авторы, даты, сборы и др.),
- визуальный и статистический анализ связей между рейтингом и характеристиками фильма,
- исследование текстовых признаков — длины и лексем названий фильмов,
- разработку Streamlit-дэшборда для интерактивной работы с результатами.

## Запуск ноутбука

Установите зависимости:

```bash
pip install -r requirements.txt
```

Установите модели spaCy
```bash
   python -m spacy download ru_core_news_sm
```

Запустите ноутбук:
```bash

```

## Запуск дэшборда

```bash

```

Установите модели spaCy
```bash
   python -m spacy download ru_core_news_sm
```

Запустите дэшборд из корня проекта:

```bash

```

## Что реализовано

- Парсинг данных с нескольких страниц сайта (список фильмов + карточки)
- Очистка и нормализация текстовых, числовых и датированных признаков
- Разведочный анализ (EDA): распределения, пропуски, динамика по годам
- Анализ зависимостей: жанры, авторы, страны, сборы, хронометраж
- NLP-анализ названий: длина, частотность, сравнение по рейтингу
- Интерактивный Streamlit-дэшборд
